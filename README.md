
# Microservices DevOps Project

## Project Overview

This project contains three independent microservices.

### 1. User Service
Provides user information.

### 2. Product Service
Provides product information.

### 3. Order Service
Provides order information.

## Technologies Used

- Git
- GitHub
- Jenkins
- Python
- Flask

## CI Pipeline

1. Checkout source code.
2. Validate repository structure.
3. Check Python syntax.
4. Display build status.

## Source Control

GitHub is used for version control and
managing application source code.

## Security

Credentials, passwords, private keys and
secret files must not be committed.
